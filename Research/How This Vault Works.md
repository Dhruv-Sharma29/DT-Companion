# How This Vault Works

The rules we follow so this stays a second brain and not a dumping ground.

## One idea, one note
Each note holds a single concept and is titled as the concept itself
(`Empathy Map`, not `Notes on empathy maps`). Link liberally with `[[wikilinks]]` —
a link to a note that doesn't exist yet is a placeholder for a note worth writing.

## Marking things as we go
Inline tags, so Obsidian search and the tag pane surface them:

| Tag | Means |
|---|---|
| `#key` | Core idea — would be on the exam / in the pitch |
| `#insight` | A non-obvious connection we worked out ourselves |
| `#question` | Unresolved, goes to [[Open Questions]] |
| `#todo` | An action to take |
| `#source` | Came from outside — cite it on the line |

Anything tagged `#key` or `#insight` also gets a one-line pointer added to
[[Key Insights]] so there is a single place to review from.

## Callouts for emphasis
```
> [!important] Title
> The thing that must not be missed.
```
Useful types: `important`, `tip`, `warning`, `question`, `example`, `quote`.

## Dates
Absolute, always — `8 Sep 2026`, never "last week".

## Where things live
- Topic notes: flat, in this folder
- [[Dashboard]]: the map — every topic note gets listed there
