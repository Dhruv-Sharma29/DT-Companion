# 🧠 In-Depth DT — Second Brain

Working vault for the in-depth Design Thinking track. Everything important we
touch gets written down here as a real note with `[[wikilinks]]`, not left in chat.

## Start here
- **[[User Problems Q&A]]** — the eight problems users face, with follow-up questions answered
- **[[My Pitch — User Segment & Features]]** — my script for slides 3 and 6, plus likely questions
- **[[Overview]]** — one-page summary of problem and solution
- **[[User Interview Guide]]** — indirect questions to check whether student founders really have this problem
- **[[Team U Deck — Know Everything]]** — the real slides, your part (User + Market), verified sources, likely questions
- **[[Presentation Prep]]** — tonight's study sheet: story, numbers, Q&A, weak points
- **[[Core Statement]]** — problem, user, opportunity. The canonical current version
- **[[Plain Explanation]]** — the project explained plainly, no pitch
- **[[MASTER — Full Problem Brief]]** — everything in one place, written for defending it to an expert
- [[Key Insights]] — the running list of things worth remembering
- [[Open Questions]] — what's still unresolved
- [[Backlog]] — everything raised and not yet done
- [[Sources]] — every external claim, link and citation
- [[How This Vault Works]] — conventions, tags, and how notes get marked
